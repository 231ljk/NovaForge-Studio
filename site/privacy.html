NovaForge 隐私政策

更新日期：2026-11-20

1. 我们收集的信息

  • 账号信息：邮箱地址、验证码，以及你授权登录的 GitHub / Gitee 昵称、头像与访问令牌。
  • 家庭与设备信息：你填写的 Home Assistant 地址、设备名称、设备状态与场景配置。
  • 使用信息：登录时间、功能使用记录与崩溃日志，用于改进稳定性。

2. 权限使用

  • 蓝牙：用于发现并连接附近的 ESP32 设备。
  • 位置信息：系统要求扫描蓝牙与局域网设备时需要，仅用于设备发现，不会上传你的精确位置。
  • 通知：用于推送设备告警与场景执行结果。
  • 本地网络 / Wi-Fi：用于与电脑端和家庭服务器通信。
  • AI 服务：仅在你主动使用时，把对话内容发送给你选择的本地模型或云端接口。

3. 信息存储与共享

数据保存在你的设备本地与你自己的家庭服务器中；账号数据仅用于登录与设备同步。除 GitHub / Gitee 登录授权外，我们不向任何第三方出售或共享你的个人信息。

4. 你的权利

你可以随时退出登录、解绑第三方账号、清除本地缓存；需要删除账号数据可联系我们。

5. 联系我们

如对本政策有疑问，可通过应用内「我的 → 帮助与反馈」与我们联系。
