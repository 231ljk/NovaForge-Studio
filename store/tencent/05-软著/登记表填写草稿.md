## 功能特点（登记版，可直接粘贴）

本软件是面向 ESP32 系列开发板的嵌入式固件开发工具，采用 Electron + React + TypeScript 架构。主要功能包括：1）基于积木块的图形化编程并自动生成 Arduino 代码；2）集成 Monaco 代码编辑器；3）集成 arduino-cli 实现固件编译、串口烧录与串口监视；4）内置本地 AI 推理服务辅助代码生成与错误排查；5）支持邮箱验证码注册登录及 GitHub/Gitee 账号绑定，敏感信息本地加密存储；6）通过局域网网关与移动端协同，支持 Home Assistant 智能家居设备控制。软件具有图形化与代码双模式、开发板配置自动迁移、验证码短时效校验、多设备账号同步等技术特点。
