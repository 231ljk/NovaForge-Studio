# NovaForge Studio 嵌入式固件开发软件 V1.0 操作说明书

（计算机软件著作权登记用 · 鉴别材料之一）

## 1. 软件概述

NovaForge Studio 是一款运行于 Windows 桌面的嵌入式固件开发软件，采用 Electron + React + TypeScript 技术栈开发，集图形化编程、代码编辑、固件编译、串口烧录、AI 辅助编程、账号管理与多设备协同于一体，主要面向 ESP32 系列开发板。

- 软件全称：NovaForge Studio 嵌入式固件开发软件
- 软件简称：NovaForge Studio
- 版本号：V1.0
- 运行环境：Windows 10 / Windows 11（64 位）
- 开发语言：TypeScript、JavaScript、HTML、CSS

## 2. 安装与启动

运行 `NovaForge-Studio-Setup-0.1.0.exe`，按向导选择安装目录完成安装。安装后可通过桌面快捷方式或开始菜单启动。软件首次启动自动初始化本地数据目录。

## 3. 功能模块说明

### 3.1 项目管理
支持新建项目、选择开发板型号（ESP32 / ESP32-S3 / ESP32-C3 等）、图形化与代码两种编程模式切换、项目保存与打开。切换开发板时自动迁移引脚配置并同步代码模板。

### 3.2 图形化编程
基于积木块的拖拽式编辑器，分类包括：控制、循环、逻辑、数学、变量、列表、函数、GPIO、串口、网络等。积木自动转换为 Arduino C++ 代码，可一键切换到代码视图查看。

### 3.3 代码编辑
内置 Monaco 代码编辑器，提供语法高亮、自动补全、错误提示，支持直接编辑 Arduino 源码。

### 3.4 编译与烧录
集成 arduino-cli 工具链，支持一键安装工具链与开发板核心、一键编译固件、通过串口烧录到开发板，实时显示编译与烧录日志及进度。

### 3.5 串口监视
提供串口数据监视功能，可查看开发板输出的调试信息。

### 3.6 AI 助手
内置本地 AI 推理服务，支持自然语言生成固件代码、解释代码、排查编译错误。推理服务可在设置中启动或停止，模型与服务器地址可配置。

### 3.7 账号中心
支持邮箱验证码注册与登录、密码登录；验证码 30 秒有效并带有同步倒计时；支持绑定 / 解绑 GitHub、Gitee 代码仓库账号，授权令牌经系统级加密后本地保存。

### 3.8 多设备协同
通过局域网网关与手机端（Android / HarmonyOS）协同，手机端可登录同一邮箱账号、同步账号信息、查看项目与编译进度、远程操作设备。

### 3.9 智能家居集成
支持配置 Home Assistant 地址与访问令牌，在软件内查看并控制家中智能设备。

### 3.10 设置
提供工具链安装状态查看与安装、AI 服务配置、账号管理、仓库绑定、软件版本信息等设置项。

## 4. 数据存储说明

软件数据（账号、项目、配置、令牌）均保存在本机应用数据目录，密码以 scrypt 哈希保存，令牌经操作系统加密保存，不上传至第三方服务器。

## 5. 卸载

通过系统「应用与功能」卸载本软件；删除应用数据目录可清除全部本地数据。
