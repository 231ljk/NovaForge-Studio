# NovaForge Studio 隐私政策

更新日期：2026 年 11 月 11 日
生效日期：2026 年 11 月 11 日

NovaForge Studio（以下简称「本软件」）由 NovaForge 团队（以下简称「我们」）开发。我们非常重视您的个人信息和隐私保护。本政策说明本软件在运行过程中如何处理您的信息。

## 一、我们收集和处理的信息

本软件为**本地优先**的桌面开发工具，绝大多数数据仅保存在您的计算机本地，不会上传至我们的服务器（我们目前亦不运营账号服务器）。

### 1. 账号信息（您主动提供时）
- 您在注册/登录时提供的**电子邮箱地址**、昵称、密码。
- 密码经 scrypt 加盐哈希后保存在本地，**明文密码不会被存储，也不会离开您的设备**。
- 邮箱验证码通过 SMTP 邮件服务发送至您的邮箱，用于验证邮箱归属。验证码仅保存哈希，30 秒后自动过期。
- 账号数据保存在本机应用数据目录（Windows 为 `%APPDATA%/novaforge-studio`）。

### 2. 第三方代码仓库授权（您主动操作时）
- 您可选择绑定 GitHub / Gitee 账号。授权过程跳转至对应平台官方页面完成，本软件不会接触您的平台密码。
- 授权后获得的访问令牌（Token）使用操作系统安全机制（Windows DPAPI）加密后保存在本地，仅用于您主动发起的仓库操作。

### 3. 网络连接
本软件在以下情形需要联网：
- 发送注册/登录验证码邮件（通过 SMTP 服务商服务器）；
- GitHub / Gitee 授权及仓库操作（访问对应平台官方接口）；
- 下载、更新编译工具链（arduino-cli 及开发板核心，来自其官方发布源）；
- 您主动配置的 AI 推理服务、Home Assistant 地址（仅访问您填写的地址）。

### 4. 局域网功能
- 手机端协同功能通过您所在局域网的 HTTP 接口实现，使用随机令牌鉴权，数据不经过公网服务器。

## 二、我们不做什么

- 不植入广告，不进行广告追踪；
- 不收集您的行为统计数据并上报；
- 不向任何第三方出售、出租您的个人信息；
- 不读取与本软件功能无关的文件。

## 三、信息的存储与保护

- 账号、项目、配置数据均存储于您本机的应用数据目录；
- 敏感信息（密码哈希、访问令牌）分别采用 scrypt 哈希与系统级加密存储；
- 卸载本软件并删除应用数据目录，即可完全删除本软件保存的全部本地数据。

## 四、您的权利

- 您可随时在「设置」中退出账号、解绑代码仓库；
- 您可通过删除本机应用数据目录注销本地账号并清除全部数据；
- 您对 GitHub / Gitee 的授权可随时在对应平台设置中撤销。

## 五、未成年人保护

本软件为开发工具，不面向未成年人收集个人信息。如您为未成年人，请在监护人指导下使用。

## 六、政策更新

本政策更新时，我们会在软件内或发布页面公布新版本，重大变更将以显著方式提示。
